# AllThingsHow: misión Leonid's Letter

## Puntos clave
- Nivel 13 (req. 10), solo Horde, no compartible. Da Leonid Barthalomew the Revered; se entrega a Glix Xizzix (barbería, Trade Quarter de Undercity).
- Cadena: Bandarion Keep → A Righteous Cause → Leonid's Letter. ID 98545.
- Recompensa: 90 XP, +100 Argent Dawn y a elegir Tim's Lost Rib, Mug of Muddled Memories o Misplaced Shooter (tipos no indicados).
