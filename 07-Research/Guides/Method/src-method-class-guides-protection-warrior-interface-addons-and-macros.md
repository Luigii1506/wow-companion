# Method: Protection Warrior, interfaz, addons y macros

## Puntos clave
- Cooldown Manager con swing timer; medidor de amenaza obligatorio; DBM/BigWigs; Plater o Platynator.
- Macros: `/startattack`; mouseover para Sunder, Taunt o Mocking Blow.
- Vanguard da un rango oculto de Charge: para macros hay que arrastrar Charge con Shift+clic desde el libro de hechizos cada vez.

## Fiabilidad
- 2026-11-04.
- Parche 1.60.1, posterior al parche del 2026-11-02.
