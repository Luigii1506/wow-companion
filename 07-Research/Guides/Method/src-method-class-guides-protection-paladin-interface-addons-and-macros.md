# Method: Protection Paladin, interfaz, addons y macros

## Puntos clave
- UI centrada (menos movimiento de ojos y ratón); Cooldown Manager en el centro y marcos de grupo cerca para utilidad. Edit Mode permite mucho sin addons.
- Addons: Ellesmere UI (alternativas ElvUI, ShadowedUI), Details con Tiny Threat (amenaza "innegociable"), Plater; ForeverAuras de Fojji en desarrollo (WeakAuras se retira por las restricciones de API modernas).
- Macros: mouseover para BoP, Blessing of Freedom y Cleanse; Divine Shield + `/cancelaura` (pulsar dos veces); `/startattack` en Holy Strike (no en Holy Shield); Advanced Target Dummy + BoP sobre el muñeco.

## Fiabilidad
- 2026-11-09. Inconsistencia interna: el muñeco con BoP dura 8 s en la página de consumibles y 10 s en la de macros.
- Parche 1.60.1, posterior al parche del 2026-11-02.
