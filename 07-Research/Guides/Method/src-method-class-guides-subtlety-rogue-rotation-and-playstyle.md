# Method — Subtlety Rogue: rotación

## Puntos clave
- **Assa Hemorrhage**: sigilo → Garrote si no está → Shank → Hemorrhage para generar → SnD → Expose Armor a 5 CP → Rupture a 3+ CP si no pierdes SnD → Eviscerate a 5 CP con Rupture activo. Vanish y Ghostly Strike para lanzar Garrote.
- **Tri-Spec Ambush**: sigilo → Ambush → Shank → Sinister Strike → SnD → Expose Armor → Eviscerate a 5 CP. Vanish y Ghostly Strike para lanzar Ambush.
- **Death Mark**: Garrote → Shank → Hemorrhage → SnD → Rupture a 3 CP → Death Mark a 5 CP → Vanish → Ambush → Cold Blood → Eviscerate antes de que acabe Death Mark.
- Venenos Deadly + Instant en todas.

## Fiabilidad
- 2026-11-04. Nombre de build distinto al de la página de talentos (Ambush frente a Eviscerate).
