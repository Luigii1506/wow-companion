# Method: Retribution Paladin, interfaz, addons y macros

## Puntos clave
- UI centrada con marcos de raid cerca: Ret es DPS pero aporta BoP y Cleanse.
- Addons: Ellesmere UI (o ElvUI, ShadowedUI), Details + Tiny Threat (también para DPS), ForeverAuras (en desarrollo).
- Macros: mouseover BoP, Freedom, Cleanse; Advanced Target Dummy + BoP.
