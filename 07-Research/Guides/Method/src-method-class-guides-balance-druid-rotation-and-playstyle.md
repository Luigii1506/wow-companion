# Method — Balance Druid: rotación y estilo de juego

## Puntos clave
- Mantener DoTs y usar Wrath para cargar Eclipse, que acelera Starfire. Lista de prioridades.
- Un objetivo: pre-pull Read Leyline (Skyborne Alliance, 5 s antes) y 2 Wrath (3 s antes) → Elune's Light (Night Elf) → Moonfire si falta → Insect Swarm si falta → Starfire con Eclipse → Wrath.
- 2–3 objetivos: DoTs en todos y Starfire/Wrath al prioritario. 4–5: DoTs en todos + Hurricane. 6+: solo Hurricane.
- Alternativa con maná positivo: Starfire solo con Omen of Clarity, ~10 % menos daño.
- Movilidad: Cat Form + Dash para volver antes a posición.
