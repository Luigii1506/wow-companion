# Method: Beast Mastery Hunter, razas y profesiones

## Puntos clave
- Diferencia entre la mejor y la peor raza: ~15 DPS.
- Tiers: **S Night Elf, Orc** · A Skyborne, Troll, Human · B Dwarf · C Tauren.
- Night Elf (Elune's Light); Human (Ruthless, Human Spirit); Orc (Blood Fury, Command); Troll (Berserking, Beast Slaying).
- Profesiones: Leatherworking + Skinning para PvE (azules fuertes desde el nivel 10); Engineering + Mining para PvP.
