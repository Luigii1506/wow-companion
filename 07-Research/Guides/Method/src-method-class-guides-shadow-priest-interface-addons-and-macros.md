# Method — Shadow Priest Interface, Addons & Macros

## Puntos clave
- Seguir CD y duración de DoT: usar el Cooldown Manager de Blizzard (editando filtros; la configuración por defecto de la beta no sirve) o un addon equivalente.
- Nameplates con debuffs visibles; boss frames bien colocados para multi-DoT.
- Addons generales: **Leatrix Plus** (QoL) y **Forever Auras** (fork de WeakAuras para Forever). Ninguno específico de Shadow.
- Macro mouseover de PW:S: `/cast [@mouseover,help,nodead][@player] Power Word: Shield` (con `#showtooltip`). Reutilizable para otros defensivos.
