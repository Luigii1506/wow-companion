# Method — Balance Druid: talentos

## Puntos clave
- Una build Core 38/0/13 (decodificada): Improved Wrath 5, Genesis 2, Moonglow 3, Improved Moonfire 2, Nature's Majesty 2, Nature's Reach 2, Nature's Splendor, Insect Swarm, Vengeance 5, Improved Starfire 5, Nature's Grace, Eclipse 3, Moonfury 5, Moonkin Form; Restoration Nature's Focus 5, Naturalist 5, Reflection 3.
- Poca flexibilidad: todo talento de daño menos Genesis (2/5) para tener todos los de maná.
- Sin problemas de maná: Genesis 5/5 en lugar de Reflection (ganancia muy pequeña). Overgrowth: mover 2 puntos de Genesis si el combate lo pide.
- Nature's Focus frente a Heart of the Wild: sin retroceso de lanzamiento Nature's Focus no aporta; HotW ~0,5 % de daño con 5 puntos. Por defecto Nature's Focus salvo doble spec.
- Legacy (árbol Resourcefulness): Gourmand, The Quick and the Dead, Reagent Economy (Rebirth sin semilla), Reinforce.
