# Method — Fire Mage: rotación y estilo de juego

## Puntos clave
- Fire Vulnerability (Improved Scorch) + Heating Up para Pyroblasts enormes; Ignite añade daño a los críticos.
- Fireball / Arcane (simple): maná → Combustion → Scorch hasta 5 de Fire Vulnerability → Arcane Blast para mantener 1 carga → Pyroblast con 3 de Heating Up → Fire Blast → Arcane Missiles con Missile Barrage → Fireball.
- Frostfire + Shatter (simple): maná → Scorch (5 cargas) → Pyroblast con 3 de Heating Up → Fire Blast con Fingers of Frost → Frostfire Bolt con FoF → Fire Blast → Frostfire Bolt.
- Avanzado: Combustion con 5 de Fire Vulnerability junto a raciales/pociones/lust; Evocation bajo 10 % de maná; Scorch rango 1 con poco maná.
- Sin rotación AoE propia en esta página. Blast Wave como daze de área en mazmorras.
