# Method — Combat Rogue: interfaz, addons y macros

## Puntos clave
- Interfaz: Cooldown Manager de Blizzard para seguir hechizos, nameplates funcionales y Personal Resource Display para la energía.
- Addons: ninguno obligatorio; un boss mod (Method Raid Tools, BigWigs o similar) y DungeonJournal para buscar mejoras.
- Macros: `/use <veneno>` + `/use 16` (mano principal) o `/use 17` (secundaria) con `#showtooltip` del slot; apertura "Pick Pocket + Garrote" (sustituible por Cheap Shot o Ambush).
