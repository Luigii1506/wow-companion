# Method — Assassination Rogue: rotación

## Puntos clave
- Reglas: Slice and Dice al 100 %, no desbordar energía, no desperdiciar combo points, cooldowns lo antes posible.
- **Poison Mutilate**: venenos Deadly + Instant antes del pull → sigilo → Garrote → Shank en CD → mantener SnD → Mutilate para generar → Expose Armor a 5 CP (si no hay Warrior con Sunder) → Eviscerate a 5 CP con SnD activo. Vanish para reaplicar Garrote.
- **Combat Shank**: igual pero con Riposte cuando salga y Sinister Strike como generador.
- Utilidad: Sap ya no saca del sigilo; Ambush/Garrote en el pull y tras Vanish (Garrote solo si el objetivo vive todo el sangrado); Cheap Shot para reducir daño; Evasion, Feint, Sprint (no rompe sigilo), Kick/Gouge/Cheap Shot para cortar.
- Otros venenos (Crippling, Mind-numbing) casi solo para PvP; los venenos se acumulan con Windfury Totem y piedras de afilar.

## Fiabilidad
- 2026-11-04. Incoherencia: llama a **Venom** remate ("finishing moves such as Venom"), pero tras el parche del 02-11 Venom es un talento pasivo que activa Shank ([[src-blizzard-forum-beta-development-notes-november-2-2360696]]).
