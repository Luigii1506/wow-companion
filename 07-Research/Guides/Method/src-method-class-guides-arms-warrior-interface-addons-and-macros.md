# Method: Arms Warrior, interfaz, addons y macros

## Puntos clave
- Cooldown Manager de Blizzard: suficiente, exportable y ahora con temporizador de swing (clave para Warrior). UI limpia.
- Addon obligatorio: medidor de amenaza (Details lo integra; o ThreatClassic2). Además boss mod (DBM/BigWigs) y placas (Plater o Platynator).
- Macros: habilidad + `/startattack` (en Forever el autoataque no empieza solo si falta rabia); Sunder Armor por mouseover.

## Fiabilidad
- 2026-11-04. Addons sin probar en el juego por nosotros.
- Parche 1.60.1, posterior al parche del 2026-11-02.
