# Method — Subtlety Rogue: talentos

## Puntos clave
- Tres builds decodificadas del widget (archivo de Method; nombres de [[src-foreverdb-class-rogue-talents]]):
  - **Assa Hemorrhage 16/5/30**: Opportunity 10–14, Imp. Ambush 15–17, Dirty Deeds 18–19, Premeditation 20, Initiative 21–23, Serrated Blades 24/26–27, Ghostly Strike 25, Elusiveness 28–29, Preparation 30, Hemorrhage 31; luego Malice 5, Imp. SnD 3, Ruthlessness 3, Lethality 2, Coup de Grace 3, Efficient Strikes 2, Setup 3, Boot Knife 5, Blood Splatter, Vigor 1, Cold Blood.
  - **Tri-Spec Eviscerate 11/19/21**: Opportunity 5, Imp. Ambush 3, Setup 2, Premeditation, Initiative 3, Serrated Blades 3, Ghostly Strike, Elusiveness 2, Preparation; luego Coup de Grace 3, Malice 5, Imp. SnD 3, Efficient Strikes 2, Precision 3, Deflection 3, Endurance 2, Composure 2, Flawless Execution, Ruthlessness 3, Aggression 3.
  - **Death Mark 16/4/31**: Opportunity 5, Dirty Deeds 2, Camouflage 3, Premeditation, Initiative 3, Serrated Blades 3, Ghostly Strike, Elusiveness 2, Hemorrhage, Preparation, Setup 3; Assassination como Assa Hemorrhage; Coup de Grace 2, Efficient Strikes 2, Boot Knife 5, Death Mark (59 en el orden del widget).
- Ventana de Death Mark: Garrote y Rupture activos → Death Mark a 5 CP → Vanish → Ambush → Cold Blood → Eviscerate.
- Setup, Heightened Senses y Ghostly Strike combinan bien en solitario pero no entran en estas builds. Elusiveness = más Vanish; Boot Knife e Initiative = más remates.

## Fiabilidad
- 2026-11-04. Aviso "basado en la beta"; las builds usan talentos del 02-11 (Boot Knife, Death Mark).
- La página de rotación llama "Tri-Spec Ambush" a lo que aquí es "Tri-Spec Eviscerate".
